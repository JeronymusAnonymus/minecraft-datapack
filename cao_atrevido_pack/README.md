# Minecraft Data Pack

This data pack is designed to enhance the Minecraft experience with custom dimensions, biomes, functions, and advancements. 

## Features

- **Custom Dimensions**: Explore new worlds with unique settings and features.
- **Biomes**: Discover various biomes, each with its own characteristics and resources.
- **Functions**: Automate gameplay with custom commands executed on load and every tick.
- **Advancements**: Track player progress with custom advancements for entering the world and completing quests.

## Installation

1. Download the data pack.
2. Place the data pack folder into the `datapacks` folder of your Minecraft world.
3. Run the command `/reload` in the game to load the data pack.

## Usage

- Use the provided functions to interact with the new features.
- Check the advancements to see your progress and unlock new content.
